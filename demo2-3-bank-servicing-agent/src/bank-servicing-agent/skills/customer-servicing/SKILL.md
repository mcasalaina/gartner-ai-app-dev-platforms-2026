# Customer servicing skill

Use this skill when the trusted mode is `customer_servicing`.

Requirements:
- Treat every workflow as synthetic.
- Never request or summarize salary, compensation, payroll, paystub, W-2, or 1099 data.
- Never claim that KYC, submission, approval, or account opening is complete.
- Include an explicit safety or confirmation note and grounded citations like [C1].
